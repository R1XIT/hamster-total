# VirusTotal-проверка скормленных файлов — Design Doc

**Дата:** 2026-07-28
**Статус:** утверждён (брейнсторминг завершён, спека одобрена пользователем)
**Проект:** Homo Antivirus (Hamser Total) — десктоп-питомец-хомяк

## Проблема

Сейчас перетаскивание файла на хомяка = мгновенное удаление в корзину (`file-dropped` → `trashFile`). Один жест — одно действие. Нужно добавить второй смысл: **проверить файл через VirusTotal** — не потеряв простое «перетащил-чтобы-удалить» как жест по умолчанию.

## Ключевые решения (из брейнсторминга)

1. **Различение жестов — вторая цель для броска.** Бросок на тело хомяка = удалить (без изменений). Пока тащишь файл, над хомяком всплывает **лупа 🔍**; бросок на лупу = проверка VirusTotal. Увёл/отпустил мимо — лупа исчезает.
2. **Итог проверки — всегда пузырь-результат** с числом «Прошёл X / Y», кнопками **Удалить / Оставить** и раскрывающимся списком движков (✓/✗). Пользователь сам решает судьбу файла; ничего не удаляется автоматически.
3. **Хэш-первый, автозагрузка при промахе.** Сначала поиск по SHA-256 (контент файла не уходит). Если VT не знает файл — файл автоматически загружается на VirusTotal.
4. **API-ключ вводит пользователь в Настройках.** Общий зашитый ключ недопустим (нарушение правил VT). Бесплатный публичный ключ: 4 запроса/мин, 500/день, файлы до 32 МБ.

## Взаимодействие (жесты)

- **Бросок на тело хомяка → удалить** в корзину (текущее поведение, не трогаем).
- **Пока идёт перетаскивание файла над окном → показывается лупа**; **бросок на лупу → `vt-check`**.
- Конец перетаскивания без броска на лупу → лупа скрывается.

### Технический компромисс: зона под лупу

Drop доставляется системой только туда, где есть окно. Значит лупа должна находиться **внутри окна хомяка**. Решение: окно хомяка становится чуть выше — сверху резервируется **зона под лупу**, прозрачная и сквозная для кликов (click-through) в покое, которая визуально проявляется и начинает принимать drop только во время активного перетаскивания файла над окном. Точная механика (постоянно увеличенное окно с per-region поведением vs. динамический ресайз окна по `dragenter`) выбирается на этапе плана; в спеке фиксируем требование: **лупа — валидная drop-цель внутри окна, видимая только во время перетаскивания, не перехватывающая клики в покое.**

## Поток проверки

```
бросок на лупу
  → хомяк играет "проверку" (существующая scanning-анимация) + пузырь "Проверяю на VirusTotal…"
  → SHA-256 файла → hashLookup (контент не уходит)
  → промах → uploadFile → pollAnalysis (15–60с)
  → нормализованный вердикт → VtVerdictBubble
```

Всё асинхронно и неблокирующе: хомяком можно пользоваться, пока идёт проверка. Прогресс отражается в пузыре (проверяю / загружаю / жду анализ).

## Пузырь-результат (VtVerdictBubble)

```
┌─────────────────────────────────┐
│   Прошёл  58 / 70                │   ← крупно; красный, если есть детекты
│                                  │
│   [ Список антивирусов ▾ ]       │   ← разворачивает перечень движков
│                                  │
│   [ Удалить ]      [ Оставить ]  │
└─────────────────────────────────┘
```

- **«Прошёл X / Y»** — X = число движков, признавших файл чистым (`harmless` + `undetected`); Y = число движков, вернувших пригодный вердикт (чистые + `malicious` + `suspicious`). Движки со статусами `timeout` / `type-unsupported` / `failure` в Y не считаются (при желании показываются нейтрально в списке).
- **Опасность:** если детектов (`malicious` + `suspicious`) > 0 — число красное, хомяк настороженный; иначе — чисто (зелёный/спокойный).
- **Список антивирусов** — раскрывающийся перечень: имя движка + ✓ (прошёл) / ✗ (не прошёл).
- **Удалить** → `trashFile` (переиспользуем существующий IPC-путь удаления). **Оставить** → закрыть пузырь, файл не трогать.

## Ключ VirusTotal

- В окне Настроек — поле **«VirusTotal API key»** + ссылка «Получить бесплатный ключ» (https://www.virustotal.com/gui/join-us).
- Пока ключа нет: бросок на лупу → пузырь «Добавьте ключ VirusTotal в Настройках»; по клику открываются Настройки.
- Ключ хранится в существующем конфиге (`AppConfig`), как обычная настройка.

## Архитектура (в стиле существующего кода)

| Модуль | Назначение |
|---|---|
| `src/main/scanner/virustotal.ts` | Клиент VT API: `hashLookup(sha256)`, `uploadFile(path)`, `pollAnalysis(id)` → нормализованный `VtVerdict { clean: number, total: number, engines: {name, category}[], detected: number }`. Fetch инъектируется для тестов. |
| `src/main/vtFlow.ts` | Оркестрация по IPC `vt-check`: хэш → hashLookup → (промах) upload → poll → вердикт/прогресс/ошибка в рендерер. Регистрирует обработчик удаления/оставления по итогу. |
| `src/main/config.ts` + Настройки | Новое поле `virusTotalApiKey` в `AppConfig`; поле ввода в `src/settings/*`, валидация в `settingsValidation.ts`. |
| `src/renderer/hamster/dragAndDrop.ts` + `renderer/index.ts` | Лупа-цель во время перетаскивания; различение `file-dropped` (тело) vs `vt-check` (лупа). |
| `src/renderer/bubble/VtVerdictBubble.ts` | Пузырь с числом «Прошёл X / Y», кнопками Удалить/Оставить и раскрывающимся списком движков. |

### Поток данных

```
drop на лупу → renderer vt-check(path)
  → main: sha256 → VT hashLookup → (miss) uploadFile → pollAnalysis
  → main: VtVerdict → renderer VtVerdictBubble
  → user: Удалить → trashFile / Оставить → dismiss
```

## Обработка ошибок (всё пузырями, неблокирующе)

| Случай | Сообщение |
|---|---|
| Нет ключа | «Добавьте ключ VirusTotal в Настройках» (клик → открыть Настройки) |
| Файл > 32 МБ | «Файл слишком большой для загрузки (лимит 32 МБ)» |
| Квота исчерпана (HTTP 429) | «Лимит VirusTotal исчерпан, попробуйте позже» |
| Нет сети / таймаут | «Не удалось связаться с VirusTotal» |
| Неверный ключ (HTTP 401) | «Неверный ключ VirusTotal, проверьте Настройки» |

## Тестирование

- **`virustotal.ts`** — юнит-тесты нормализации вердикта (подсчёт clean/total/detected из ответа VT), ветки хэш-хит / промах-с-загрузкой / ошибки — с мок-fetch (по образцу `defenderParser.test.ts`).
- **drag-drop** — юнит-тест различения «лупа vs тело» → `vt-check` vs `file-dropped`.
- **VtVerdictBubble** — рендер числа, кнопок, раскрытия списка (jsdom, по образцу `Bubble.test.ts`).

## Вне рамок (YAGNI)

- Никакой автозагрузки без броска на лупу (фоновый Defender-скан папок остаётся как есть, отдельно).
- Никакого автоудаления по вердикту VT — решение всегда за пользователем.
- Никакого кэша прошлых вердиктов, истории проверок, пакетной проверки нескольких файлов — по одному файлу за жест.
